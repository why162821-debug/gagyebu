# 가계부

HTML 파일 하나로 된 가계부입니다. 설치나 서버 없이 브라우저에서 바로 씁니다.

**바로 쓰기:** https://why162821-debug.github.io/gagyebu/

- 지출·수입 기록, 수정·삭제(실행 취소 가능)
- 메모 대신 **귀여운 그림이 달린 분류**를 눌러서 선택 (식비·교통·주거·통신·쇼핑·문화·여가·의료·건강·교육·경조사·급여·용돈·부수입·기타)
- 월별 수입·지출·잔액 요약, 지난달 대비 지출 증감
- 분류별 지출 비율
- 날짜별 목록, 수입/지출 필터와 분류 검색
- CSV 내보내기(엑셀용), JSON 백업·불러오기

## 데이터는 어디에 저장되나요?

기록은 서버가 아니라 **지금 쓰는 브라우저 안(localStorage)** 에만 저장됩니다.
이 저장소나 웹사이트에는 아무 기록도 올라가지 않습니다.

그래서 다른 기기나 다른 브라우저에서는 기록이 보이지 않고, 브라우저 기록을 지우면 함께 사라집니다.
화면 아래 **데이터 관리 → 백업 저장** 으로 가끔 백업해 두세요.
