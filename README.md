## 데이터는 어디에 저장되나요?

기록은 **Supabase DB**(`transactions` 테이블)에 저장돼서 어느 기기·브라우저에서 열어도 같은 내용이 보입니다.

**로그인이 없습니다.** 이 페이지 주소를 아는 사람은 누구나 기록을 보고, 고치고, 지울 수 있어요.
(페이지에 들어 있는 Supabase 키는 공개용 키이고, DB 정책이 익명 접근을 허용하도록 열려 있기 때문이에요.)
주소를 다른 사람에게 나눠 주지 마시고, 가끔 **데이터 관리 → 백업 저장**으로 백업해 두세요.

예전 버전(브라우저에만 저장)에서 쓰던 기록이 남아 있으면, 페이지 위쪽에 **서버로 옮기기** 안내가 떠요.
옮기면 이 브라우저의 예전 기록은 지워집니다.

## DB 설정

- 프로젝트: Supabase `ggb-0921`
- 테이블 `public.transactions`: `id`, `seq`(입력 순서), `date`, `type`(`income`/`expense`), `cat`(분류), `memo`, `amount`, `sample`(샘플 데이터 표시)
- RLS(행 단위 보안)는 켜져 있고, `anon`·`authenticated` 모두 모든 행에 접근할 수 있는 정책(`open transactions`)이 있어요.

화면에 “서버가 이 앱의 접근을 막고 있어요”라고 뜨면 이 정책이 없어진 것이니 Supabase에서 위 정책을 다시 확인하세요.
